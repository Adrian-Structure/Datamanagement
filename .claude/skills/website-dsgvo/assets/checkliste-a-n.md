# Prüfliste A–N — „Website DSGVO/TDDDG-konform?" (Stand der Fachquelle: 08.07.2026)
Je Punkt markieren: ✅ OK · ⚠️ OFFEN · — trifft nicht zu. Das ausgefüllte
Dokument ist die Vorlage für den Anwalts-Check — keine Rechtsberatung.

**A. Rechtsgrundlage & Grundprinzip**
- [ ] Für JEDE Datenverarbeitung Rechtsgrundlage (Art. 6) oder wirksame Einwilligung
- [ ] Nutzer transparent informiert
- [ ] Technische/organisatorische Schutzmaßnahmen getroffen
- [ ] Betroffenenrechte gewahrt

**B. Zwei-Stufen-Prüfung je Technologie**
- [ ] Stufe 1 (§ 25 TDDDG): Endgeräte-Speicherung/-Auslesen? → Einwilligung oder Ausnahme
- [ ] Stufe 2 (DSGVO): personenbezogene Daten? → Rechtsgrundlage benannt
- [ ] Vollständiger Technologie-Überblick liegt vor (Scan + Nutzer-Befragung)

**C. Hosting/AV**
- [ ] Externer Hoster → AV-Vertrag geschlossen
- [ ] Webdesign/Backup/Wartung mit Zugriffsmöglichkeit → AV-Vertrag

**D. Verschlüsselung**
- [ ] HTTPS mit aktuellem TLS (empfohlen 1.3; Vorgaben: BSI TR-02102-2)
- [ ] Gültiges CA-Zertifikat, Erneuerung geregelt
- [ ] Bei Dateneingabe (Formular/Login): Verschlüsselung auch nach Art. 32 DSGVO gewährleistet

**E. Server-Logfiles**
- [ ] Rechtsgrundlage (i. d. R. Art. 6 Abs. 1 lit. f)
- [ ] Nutzung nur Sicherheit/Fehleranalyse/Verwaltung
- [ ] In der Datenschutzerklärung erläutert (Kategorien, Zwecke, Dauer)

**F. Kontaktformular**
- [ ] Nur notwendige Felder (Datenminimierung)
- [ ] Optionales als freiwillig gekennzeichnet
- [ ] HTTPS-Übertragung
- [ ] In der Datenschutzerklärung beschrieben
- [ ] Bewerbungsformular vorhanden? → § 26 BDSG (Bewerber = Beschäftigte) beachtet

**G. Tracking/Analyse**
- [ ] Einwilligung VOR Aktivierung (Consent-Banner)
- [ ] Transparent in der Erklärung
- [ ] Im Verzeichnis der Verarbeitungstätigkeiten dokumentiert
- [ ] Tool-Einstellungen auf Datensparsamkeit geprüft
- [ ] Bei Google Analytics: Vertragsdoku + Drittland-Angabe
- [ ] Einwilligungen werden protokolliert (Nachweis nach Art. 7 Abs. 1 möglich)

**H. Social-Media-Plugins**
- [ ] Shariff/2-Klick statt Direkteinbindung — oder nur Profil-Links

**I. Eingebundene Videos**
- [ ] youtube-nocookie genutzt (ersetzt die Einwilligung NICHT)
- [ ] Laden erst nach Einwilligung/2-Klick
- [ ] In der Erklärung beschrieben

**J. Cookies**
- [ ] Ohne Einwilligung nur technisch notwendige (Warenkorb, Login, Session)
- [ ] Alle übrigen erst NACH Einwilligung gesetzt

**K. Webfonts**
- [ ] Lokal ausgeliefert (kein dynamisches Nachladen von Drittservern)
- [ ] Falls extern: Rechtsgrundlage + Angabe in der Erklärung

**L. Datenschutzerklärung**
- [ ] Rechtsgrundlagen genannt
- [ ] Betroffenenrechte inkl. Beschwerderecht bei einer Aufsichtsbehörde
- [ ] Datenschutzbeauftragter (falls bestellt) mit Kontakt
- [ ] DSB-Pflicht geprüft (§ 38 BDSG: ≥ 20 Personen ständig automatisiert verarbeitend? DSFA-Pflicht?)
- [ ] Erklärung UND Impressum vorhanden und verlinkt
- [ ] Impressum von JEDER Unterseite leicht erreichbar (max. 2 Klicks, auch Landing-/Hub-Seiten)

**M. Datenweitergabe an externe Dienstleister**
- [ ] Auf Einwilligung / Vertragserfüllung / berechtigtes Interesse gestützt
- [ ] TDDDG-Anzeigepflicht bei Weiterleitung beachtet
- [ ] Kein Datenverkauf an Dritte

**N. AV-Verträge**
- [ ] Für jeden weisungsgebundenen Dienstleister geschlossen
- [ ] Inhalt: Art/Zweck, Weisungsrechte, TOM, Pflichten
- [ ] Standard-AV auf Passung geprüft

**Nicht von der Fachquelle abgedeckt (gesondert prüfen):**
- [ ] Newsletter/Double-Opt-in
- [ ] Drittlandübermittlung systematisch (SCC/Angemessenheit)
- [ ] Google Maps / weitere Embeds
